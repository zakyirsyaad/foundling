# Rencana implementasi website Foundling (`web/`)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangun situs Next.js di `web/`: landing (`/`, `/proof`, `/trust`, `/terms`) dan app (`/app`, `/app/cycles`, `/app/portfolio`) yang membaca vault dari RPC, menandatangani lewat wallet pengguna, dan mengantar deposit dari Base, Arbitrum, dan Ethereum lewat 1Click.

**Architecture:** Satu proyek Next.js (App Router) di npm workspace. Logika murni ada di `lib/` dan diuji unit dengan Vitest. Komponen per fitur ada di `features/`, rute tipis di `app/`. Server membaca RPC dengan cache, browser membaca ulang tiap 10 detik. Riwayat dari API terpisah bersifat opsional: bila API mati, hasilnya status tertunda. Semua jalur keluar hanya butuh RPC dan wallet.

**Tech Stack:** Next.js 16, React 19, TypeScript strict, Tailwind v4, shadcn/ui tema `neutral`, `@hot-labs/near-connect`, `@defuse-protocol/one-click-sdk-typescript`, zod, `@noble/hashes`, Vitest, Playwright, `@axe-core/playwright`, dependency-cruiser.

**Spec:** `docs/WEBSITE.md` (utama), `docs/SPEC.md` §1, §3, §9, dan `docs/PLAN.md`. Token desain ada di `docs/design/foundling-mono.tokens.json` (salinan design system Foundling Mono).

**Cakupan.** Rencana ini hanya `web/` dan job CI `Web`. `packages/db/`, `indexer/`, `api/`, dan antrean bukti (W2, W3, W6) punya rencana sendiri. Web memakai kontrak API di WEBSITE §5 lewat `lib/history/` dan server tiruan di tes, jadi tidak menunggu backend. Urutan tugas mengikuti W1, W4, W5, W7, W8 di WEBSITE §10. Bila bentrok dengan pekerjaan chain di PLAN, pekerjaan chain didahulukan.

## Global Constraints

- Copy website dalam bahasa Inggris. Tidak ada APY, yield, return, atau janji hasil. Landing tidak menampilkan angka kinerja dan tidak mengajak menyetor.
- Perubahan harga per share hanya di app, berlabel "Share price since start", dengan periode dan jumlah siklus, tanpa disetahunkan.
- npm workspaces. `npm ci --ignore-scripts` di semua tempat. `.npmrc` memakai `save-exact=true` dan `ignore-scripts=true`. `verify.py` dan `make quick` tetap tidak butuh Node.
- Versi dependensi dipatok persis. Pilih versi yang sudah terbit minimal 14 hari saat dipasang (`npm view <pkg> time --json`).
- Action GitHub dipatok ke SHA commit, seperti `ci.yml`. `npm audit --audit-level=high`. Required check hanya berubah atas permintaan lead.
- Monokrom tema `neutral` shadcn/ui. Warna hanya untuk status, selalu dengan kata, menurut tabel `Status` WEBSITE §4.
- Inter untuk teks, Geist Mono untuk angka, hash, akun, dan perintah, keduanya di-host sendiri. Lisensi OFL dicatat di `THIRD_PARTY_NOTICES.md`.
- Hero 64 px (56 px di bawah 768 px), teks landing 16 px, teks app 14 px. Border 1 px, radius 8 px card dan 6 px tombol/input.
- Semua jumlah token memakai `BigInt`. Tidak ada `Number` untuk jumlah.
- Website tidak memegang kunci atau rahasia. Variabel `NEXT_PUBLIC_` hanya konfigurasi publik.
- Landing di-cache 30–60 detik di server. Render server `/app` di-cache paling lama 20 detik. Browser refresh tiap 10 detik hanya saat tab terlihat. Data app di atas 60 detik dianggap tidak terbaca.
- Tanpa `dangerouslySetInnerHTML`. Tautan `wasm_url` hanya `https`. CSP memakai nonce per request.
- Deployment testnet menampilkan banner `MOCK` di semua halaman dan tidak merender deposit dari chain lain.
- Mock wallet hanya ada di build tes. CI memastikan tidak ikut ke build produksi.
- Cakupan tes minimal 80% di `web/lib/` dan `web/features/`.
